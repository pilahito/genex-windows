GENEX WINDOWS COMMUNITY — what you are installing

Genex Windows Community is a Windows version based on the Genex code base, with some improvements. Genex is the desktop studio where AI agents build 3D games with three.js, created by genex.games (https://github.com/genex-games/genex-desktop) and released under the MIT license.

This version is UNOFFICIAL: it is not made or endorsed by the Genex authors, and all credit for the original program goes to them.

This will install:
  • The application (about 475 MB on disk).
  • Start menu and/or desktop shortcuts, if you tick them.
  • Optional plugins, if you tick them (you can enable or remove them later in Plugins):
      – Mobile games: touch controls, installable game (PWA) and Android APK.
      – APK analysis: analyse your own APKs with apktool and jadx (analysis only).
  • An entry in Windows "Installed apps" to uninstall it.

Where your data lives:
  • Settings and conversations: %APPDATA%\Genex Windows Community
  • Your games: the "AI Games" folder in your user profile.
Uninstalling keeps your data unless you choose to delete it.

Notes:
  • It tells you when a new version is published at https://github.com/pilahito/genex-windows/releases (can be turned off in Settings › About). It does not touch an official Genex install.
  • The installer is not signed: Windows SmartScreen may warn ("More info" › "Run anyway").
  • Works with local AI (Jan, LM Studio, Ollama…) or OpenAI-compatible APIs.
