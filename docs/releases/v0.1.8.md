# Genex Windows Community v0.1.8

Una versión para Windows basada en el código base de [Genex](https://github.com/genex-games/genex-desktop) (de genex.games, licencia MIT), con algunas mejoras. No oficial: todo el mérito del programa original es de sus autores. Novedades principales: **instalador con asistente en español** (también en inglés), que sustituye al instalador silencioso de Squirrel, y **actualizaciones dentro de la app** desde las releases de este repositorio.

## Descargas

| Archivo | Para qué |
| --- | --- |
| `GenexWindowsCommunity-Setup-0.1.8.exe` | **Instalador con asistente** (recomendado). |
| `Genex Windows Community-win32-x64-0.1.8.zip` | Versión portable: descomprimir y abrir `genex-community.exe`. |

## Instalador con asistente (Inno Setup)

Al abrir el `Setup` verás, paso a paso:

1. **Idioma**: Español o English.
2. **Para quién instalar**: solo para ti (recomendado, sin permisos de administrador) o para todos los usuarios (Archivos de programa).
3. **Licencia MIT**: hay que marcar «Acepto el acuerdo».
4. **Información**: qué es Genex Windows Community (fork no oficial, licencia MIT), cuánto ocupa, qué plugins trae y dónde guarda tus datos.
5. **Carpeta de destino**: por defecto `%LOCALAPPDATA%\Programs\Genex Windows Community` (o `C:\Program Files\Genex Windows Community` si instalas para todos). Puedes elegir otra con «Examinar…».
6. **Componentes**: el programa (obligatorio) y los **plugins opcionales** *Juegos para móvil* y *Análisis de APK*. Tipos: completa, solo el programa o personalizada.
7. **Accesos directos**: menú Inicio y/o escritorio (casillas).
8. **Listo para instalar** → instalar → casilla **«Abrir Genex Windows Community ahora»**.

- Se registra en **Configuración › Aplicaciones › Aplicaciones instaladas** con su desinstalador.
- **Al desinstalar, tus datos se conservan** (`%APPDATA%\Genex Windows Community`: ajustes, conversaciones, plugins instalados). El desinstalador pregunta si quieres borrarlos; la respuesta por defecto es «No». Tus juegos («AI Games») nunca se tocan.
- Los plugins que **desmarques** quedan instalados pero **desactivados** al crear tu perfil; puedes activarlos o quitarlos cuando quieras en Plugins. En un perfil que ya existía no se cambia nada.
- Si actualizas sobre la misma carpeta, el asistente la recuerda. Cierra Genex antes de instalar (el asistente avisa si sigue abierto).
- Instalación desatendida (para scripts): `GenexWindowsCommunity-Setup-0.1.8.exe /VERYSILENT /CURRENTUSER /COMPONENTS="main,plugins,plugins\mobile"`.

## Actualizaciones dentro de la app (nuevo)

Genex Windows Community ya se actualiza solo, **desde las releases de este repositorio** (`pilahito/genex-windows`), nunca desde la versión oficial de Genex.

- Al iniciar (unos 20 s después) mira si hay una release más nueva. Si la hay, abre la ventana **«Hay una nueva versión vX»** con las novedades de la release y tres botones:
  - **Actualizar ahora**: descarga `GenexWindowsCommunity-Setup-X.exe`, comprueba que el **tamaño y el SHA-256** coinciden con los que publica GitHub para ese archivo, cierra Genex y ejecuta el instalador en modo silencioso en la misma carpeta (con los mismos plugins y accesos directos). Al terminar, Genex se vuelve a abrir. Si la comprobación falla, no ejecuta nada y te ofrece abrir la página de la release.
  - **Más tarde**: vuelve a preguntar en el próximo arranque.
  - **Omitir esta versión**: no vuelve a avisar de esa versión (sí de la siguiente).
- **Versión portable (zip)**: «Actualizar ahora» abre la página de la release para descargar el zip nuevo.
- **Ajustes › Acerca de**: botón **«Buscar actualizaciones»** (también en el menú Ayuda) y el interruptor **«Buscar actualizaciones al iniciar»** para desactivar la comprobación automática. Se guarda en `community.json` (`"updates": { "autoCheck": false }`).
- La ventana de novedades no ejecuta scripts: el Markdown se muestra como texto con formato y los enlaces se abren en tu navegador.
- Solo consulta la API pública de GitHub (`api.github.com/repos/pilahito/genex-windows/releases/latest`); no envía datos tuyos.

> Desde la v0.1.7 o anteriores no hay actualizador: instala esta v0.1.8 a mano una vez. A partir de aquí, las siguientes llegarán solas.

## Otros cambios

- CI: el workflow instala Inno Setup y compila el asistente en cada build; la Release ya no adjunta los archivos de Squirrel (`nupkg`, `RELEASES`).
- `scripts/build-installer.mjs` para compilar el asistente en local (`winget install JRSoftware.InnoSetup`, después `npm run package` y `node scripts/build-installer.mjs`).
- Test nuevo de las opciones de plugins del instalador.
